엘든링 장비 프리셋 앱의 첫 베타입니다. Windows Steam판 엘든링 App/Regulation 1.17.1과 DLC를 대상으로 개발 중입니다.

### 다운로드 및 실행

아래 Assets에서 **EldenRingPresets-Test.exe**를 다운로드하세요. Python 설치나 PowerShell 명령은 필요 없습니다.
기존 프리셋 앱과 원본 Loadout Manager를 종료한 뒤 새 EXE를 실행하세요. 기존 프리셋은 유지됩니다.
오프라인 게임에서 캐릭터를 불러온 상태로 사용하세요. 첫 사용 전 세이브를 백업해 주세요.

### 조작법

- 키보드: F1~F4 저장, 숫자 1~4 불러오기.
- Xbox 패드: RT+십자키 불러오기, LT+RT+십자키 저장.
- PlayStation 패드: R2+십자키 불러오기, L2+R2+십자키 저장.
- 십자키 방향: ↑ 1번, → 2번, ↓ 3번, ← 4번.
- 선택 메뉴: Ctrl+F 또는 LT+RT+RS(L2+R2+R3). 패드에서는 십자키 선택 후 A/× 확인, B/○ 취소.

패드 입력은 기본으로 켜져 있습니다. 앱의 `패드:` 줄에 연결된 장치와 누른 버튼이 표시됩니다.
단축키는 게임 창에 포커스가 있을 때 작동합니다. 게임의 원래 키보드·패드 입력은 차단하지 않습니다.

### 이번 베타의 변경 및 확인 결과

- 원본 Loadout Manager와 같은 기본 패드 조합을 적용했습니다.
- XInput 첫 번째 장치만 읽던 구현을 pygame/SDL 입력으로 교체했습니다.
- 패드 자동 연결·해제 감지, 여러 장치의 개별 입력 처리, 게임에 포커스가 있을 때의 백그라운드 입력을 추가했습니다.
- 저장 조합에서 LT를 놓았을 때 불러오기가 연이어 실행되지 않도록 했습니다.
- 테스트 35개, Windows EXE 빌드 및 앱 창 실행 검사 통과.
- SDL 가상 패드로 연결·해제, 트리거·십자키 조합 확인.
- 사용자 PC에서 이전 빌드의 키보드 단축키 동작 확인.

### 알려진 제한

실제 Xbox/PlayStation 패드를 연결한 게임 내 동작은 아직 확인이 필요합니다. DLC 전체 장비에 대한 검증도 완료되지 않았습니다.
무기·방어구·탈리스만 프리셋을 지원하며, 능력치·레벨 및 기억한 마법 복원은 기본으로 꺼져 있는 실험 기능입니다.
원본 Loadout Manager의 모든 기능을 구현한 상태는 아닙니다. 소모품·화살·볼트·파우치, 아이콘·이름 데이터베이스,
스탯 편집, 미믹 전용 프리셋, 트레이 상주 및 전체 설정·가져오기/내보내기는 포함하지 않습니다.

`BUILD-INFO.json`에는 빌드한 소스 커밋과 EXE SHA-256이 기록되어 있습니다. `SHA256SUMS.txt`로 다운로드 파일을 확인할 수 있습니다.
